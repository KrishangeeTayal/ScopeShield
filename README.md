# ScopeShield

**Know What's Included. Before You Say Yes.**

ScopeShield is a local AI-powered scope-creep detector for freelancers. It compares new client requests against an original project agreement, highlights potential scope changes, and helps draft polite, professional replies.

## Features

- Analyze client requests against an agreed project scope.
- Identify requests that appear included, potentially additional, or need clarification.
- Highlight relevant agreement evidence and explain findings.
- Draft professional replies to clients.
- Keep a Scope Ledger of previous analyses.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Gemma 3:4b
- Ollama for local AI inference

## Prerequisites

Before running ScopeShield, install:

- [Node.js](https://nodejs.org/) (LTS recommended)
- [Git](https://git-scm.com/)
- [Ollama](https://ollama.com/download)
